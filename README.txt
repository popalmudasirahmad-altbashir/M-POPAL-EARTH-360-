PROJECT

M-POPAL-EARTH

FILES

- Earth edges
- Map lines
- Highlights
- Important interface details

FEATURES

3D Earth

Interactive 3D globe designed for mobile and desktop.

360 Degree Control

Users can rotate the Earth by dragging with a finger or mouse.

Zoom

Users can zoom the Earth using touch gestures or mouse controls.

INTERACTION

Touch:

Drag with one finger to rotate the Earth.

Pinch:

Use two fingers to zoom.

Mouse:

Drag to rotate.

Mouse Wheel:

Zoom in and out.

DEVELOPMENT RULE

The project should remain modular.

Major features should be separated between:

HTML
CSS
JavaScript
Earth data
Map data

IMPORTANT

Do not replace the entire project when adding a small feature.

New features should be integrated into the existing structure
whenever possible.

PROJECT GOAL

Create a highly polished, futuristic and interactive
